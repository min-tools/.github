# Security

Report security vulnerabilities privately. Do not post vulnerability details in a public issue.

| App | Private report | Privacy policy |
| --- | --- | --- |
| Langmin for macOS | [Report a Langmin vulnerability](https://github.com/min-tools/langmin-macos/security/advisories/new) | [Langmin privacy](https://min.tools/langmin/privacy/) |
| Pastemin for macOS | [Report a Pastemin vulnerability](https://github.com/min-tools/pastemin-macos/security/advisories/new) | [Pastemin privacy](https://min.tools/pastemin/privacy/) |
| Netmin for macOS | [Report a Netmin vulnerability](https://github.com/min-tools/netmin-macos/security/advisories/new) | [Netmin privacy](https://min.tools/netmin/privacy/) |

If GitHub does not show a private reporting form for the affected repository, use the app's support page and ask for a private contact channel without including the vulnerability details:

- [Langmin support](https://min.tools/langmin/support/)
- [Pastemin support](https://min.tools/pastemin/support/)
- [Netmin support](https://min.tools/netmin/support/)

Include the affected app and version, your macOS version, the security impact, and the shortest reliable steps to reproduce the issue. Remove credentials, private content, and unrelated data from logs or screenshots.

You will receive an acknowledgement within a few days. Confirmed fixes will be prepared and released as soon as they are ready.
