<h1 align="center">min-tools/.github</h1>

<p align="center">Organization-wide files for <a href="https://min.tools/">Min Tools</a>, a growing collection of focused apps that keep to themselves, on the Mac and in the browser.</p>

| File | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | The organization profile shown at [github.com/min-tools](https://github.com/min-tools). |
| [profile/images/](profile/images/) | Min Tools branding, app icons, and light and dark profile screenshots. |
| [SUPPORT.md](SUPPORT.md) | Default support information for repositories in the organization. |
| [SECURITY.md](SECURITY.md) | Default security-reporting policy for repositories in the organization. |

The current apps are for macOS, Chrome, and Firefox. Linux and Windows versions are coming.

## Current apps

- [Langmin for macOS](https://github.com/min-tools/langmin-macos) — a language assistant for proofreading, rewriting, explaining, summarizing, translating, and dictionary lookups.
- [Pastemin for macOS](https://github.com/min-tools/pastemin-macos) — searchable clipboard history for copied text and images.
- [Netmin for macOS](https://github.com/min-tools/netmin-macos) — network diagnostics for DNS, routing, local devices, mail, TLS, websites, and ports.
- [Keymin for macOS](https://github.com/min-tools/keymin-macos) — an editor for the skhd hotkey daemon's configuration.
- [Paletmin for Chrome](https://github.com/min-tools/paletmin-chrome) and [Paletmin for Firefox](https://github.com/min-tools/paletmin-firefox) — a browser extension that switches the current tab between a website's light and dark palette.

Product pages, privacy policies, terms, and support are published at [min.tools](https://min.tools/).
